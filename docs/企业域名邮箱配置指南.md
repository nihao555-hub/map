# 企业域名邮箱配置指南（外贸开发信专用）

> 目标：用 `sales@你的域名.com` 这样的企业地址发开发信，不进垃圾箱。
> 总成本：**域名约 55～80 元/年，其余全部免费**。

## 为什么必须自有域名

- 免费共享域名（如 `huali.freeqiye.com`）的 DNS 归服务商管：
  `freeqiye.com` 的 SPF 为 `include:spf.163.com -all`（只允许网易服务器发信、硬拒绝），
  DMARC 为 `p=quarantine`（不合规的信直接进垃圾箱）。
  因此**任何第三方通道（Brevo 等）都无法合规地用该地址做发件人**。
- 个人邮箱（QQ/163）做 B2B 发件人显得不专业，且群发风控严。
- 自有域名 = 自己控制 SPF/DKIM/DMARC + 自己积累发信信誉，这是所有正规
  外贸冷邮件的标准配置。

## 第一步：买域名（约 10 分钟）

- 到阿里云/腾讯云/Cloudflare 任意一家注册一个 `.com`（约 55～80 元/年）。
- 建议与公司/产品相关、简短易读，例如 `hualitools.com`。
- 不需要建网站；后续只用它的 DNS 解析。

## 第二步（方案 A，最简单）：腾讯企业邮箱免费版收发一体

> 2026 年现状：腾讯企业邮箱基础版免费、账号数无上限、支持自有域名，
> 通过企业微信开通；支持 IMAP/SMTP（需在设置中生成"客户端专用密码"）。
> 注意：阿里企业邮箱免费版自 2026-03-04 起不再支持第三方客户端登录
> （无 SMTP/IMAP），不适用本系统。

1. 下载企业微信 → 管理后台 → 协作 → 邮箱，开通企业邮箱并绑定你的域名。
2. 按提示在域名 DNS 添加记录（腾讯会给出精确值，通常为）：

   | 类型 | 主机记录 | 记录值 | 优先级 |
   |---|---|---|---|
   | MX | @ | `mxbiz1.qq.com` | 5 |
   | MX | @ | `mxbiz2.qq.com` | 10 |
   | TXT | @ | `v=spf1 include:spf.mail.qq.com ~all` | - |
   | TXT | `_dmarc` | `v=DMARC1; p=none; rua=mailto:dmarc@你的域名` | - |

3. 创建账号 `sales@你的域名`，在邮箱设置里开启 IMAP/SMTP 并生成客户端专用密码。
4. 回到本系统「设置」：
   - 邮箱服务商预设选「腾讯企业邮箱」（SMTP `smtp.exmail.qq.com:465`、IMAP `imap.exmail.qq.com:993` 自动填好）
   - 企业邮箱填 `sales@你的域名`，授权码填客户端专用密码
   - 发信通道保持「邮箱 SMTP 直发」→ 保存 → 点「测试连接」
     （会自动探测外发权限，通过即可用）

方案 A 发信时 SPF 对齐即可通过 DMARC，收发同一个箱子，最省事。
新邮箱额度有限，前期保持系统默认的预热节奏（首日 15～20 封，逐日 +5）。

## 第三步（方案 B，到达率最优）：发信升级走 Brevo，收信仍用腾讯

> 适合把量提到每天上百封、或方案 A 遇到外发限制时升级。发收分离：
> 发件走 Brevo API（免费 300 封/天，DKIM 完全对齐），收件走腾讯 IMAP。

1. 到 brevo.com 免费注册 → Senders & Domains → **Authenticate your domain**，
   按提示在域名 DNS 添加 Brevo 给出的记录（DKIM 两条 CNAME + 一条验证 TXT，
   以后台显示为准）。DMARC 建议从 `p=none` 起步观察报告。
2. Senders 里添加发件人 `sales@你的域名`（验证邮件会寄到腾讯箱，点链接确认）。
3. SMTP & API → 生成 API Key（`xkeysib-` 开头）。
4. 本系统「设置」：
   - 企业邮箱仍为 `sales@你的域名`（From/Reply-To/IMAP 都是它）
   - IMAP 保持腾讯（收信不变），发信通道切换为「Brevo API」，粘贴 API Key
   - 保存 → 测试连接
5. 客户回信照常进腾讯箱 → 系统 IMAP 照常收，回复检测/意向评估/自动驾驶全链路不变。

## 发信节奏建议（与系统默认一致）

- 新域名先"养"：首周每天 ≤ 20 封（系统预热默认），逐步加量；
- 只发有效地址（系统已自动清洗），退信/退订自动止损抑制；
- 周二～周四客户当地上午发送（系统默认窗口），回复率最高；
- DMARC 从 `p=none` 观察 2～4 周报告，正常后可升级为 `p=quarantine`。

## 系统内对应关系速查

| 系统设置项 | 方案 A | 方案 B |
|---|---|---|
| 企业邮箱（From/Reply-To/IMAP 账号） | `sales@你的域名` | `sales@你的域名` |
| 授权码 | 腾讯客户端专用密码 | 腾讯客户端专用密码（IMAP 用） |
| SMTP 主机 | `smtp.exmail.qq.com:465` | 任意（不使用） |
| IMAP 主机 | `imap.exmail.qq.com:993` | `imap.exmail.qq.com:993` |
| 发信通道 | 邮箱 SMTP 直发 | Brevo API + API Key |
