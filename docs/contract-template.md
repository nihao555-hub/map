## 第二条　合作内容（服务内容）

1. 双方基于各自优势，就本地商户线索获取与邮件触达达成合作。
2. 乙方基于自身产品与技术优势，为甲方提供以下服务：

   1. **地图数据采集获客**：按甲方指定关键词、地区、行业等条件，从谷歌地图批量采集商户线索，提取名称、地址、电话、网站、评分、评论数、营业信息、邮箱等字段；支持去重、按数量/区域网格全量采集，并导出 CSV/JSON 或写入数据库。
   2. **AI 智能开发信撰写**：基于每个客户的官网背景调研与采集到的真实数据，以资深外贸业务口吻逐客户撰写个性化开发信；内置“去 AI 腔”与合规校验，禁止编造数据与承诺；未启用 AI 时使用内置多语言模板兜底。
   3. **定时群发与自动跟进**：按每个客户所在地时区在其当地工作日上午投递；三封“同一邮件会话”序列（首封 + 两次礼貌跟进），新邮箱预热限量、随机发送间隔，客户一旦回复即自动停止后续跟进。
   4. **收信与意向评估**：通过 IMAP 自动收取客户回信，识别“回复 / 退信 / 退订 / 投递延迟”；对回复按关键词与 AI 输出 0–100 意向评分与中文标签；退信、退订邮箱进入全局抑制名单，跨活动停止发送。
   5. **客户工作台与数据分析**：提供客户名单（按“全部 / 未联系 / 跟进中 / 已回复”筛选）、完整收发信记录、AI 生成内容与质量评估、以及活动触达、回复率、退信、抑制等经营看板。
   6. **回信协助**：AI 依据往来记录生成回信草稿供人工审核，最终发送均需人工确认；系统不代替甲方自动回复客户。

3. 合作产品清单、服务量与价格详见 **附件 1**；服务模式、范围与服务等级详见 **附件 2**。

## 第四条　甲方的权利和义务

1. 甲方应按乙方要求提供开展服务所需的信息（如目标地区、行业关键词、企业邮箱及其客户端授权码等），并保证其提供信息的真实、合法。
2. 甲方应保证其用于发送开发信的域名与邮箱具备合法发信资质，配合完成 SPF/DKIM/DMARC 等发信认证配置。
3. 甲方应确保开展的邮件触达符合目标收件人所在地法律法规（如 GDPR/ePrivacy、CAN-SPAM、CASL 及当地反垃圾邮件规定），对营销对象的合法联系依据负责。
4. 甲方应按本协议约定支付服务费用。

## 第五条　乙方的权利和义务

1. 乙方负责向甲方提供上述数据采集、AI 开发信收发、意向评估与客户管理等产品的技术支持与服务。
2. 解决方案涉及的云端计算资源、AI 模型接口（或对接甲方自有 LLM 密钥）由相应约定方提供；甲方自有邮箱授权码与 AI 密钥仅在运行进程内存中使用，乙方不做持久化存储。
3. 乙方保证所提供的产品与服务拥有合法权利，不侵犯任何第三方权益。
4. 乙方应在本协议签订之日起 ______ 个工作日内完成部署/开通并交付使用。
5. 乙方仅提供工具与技术服务，**不保证任何具体的回复率、成交率或客户获取数量**；实际效果取决于名单匹配度、甲方产品价值、发信域名信誉、内容质量与合规性等因素。

## 第六条　保密责任

1. 保密信息指：双方在合作中接触到的对方及/或其关联公司、客户的与项目有关的任何信息与数据，无论以何种媒介承载。
2. 双方保证保密信息仅用于与本合作相关的用途，妥善保存，未经对方书面同意不得向第三方披露。
3. 因一方原因造成对方或其客户信息泄露的，泄露方应承担相应违约责任。
4. 采集所得数据与客户往来记录的所有权及使用责任归属由双方另行书面约定。
