# 地图获客 · 完整操作文档

面向业务用户的操作说明（技术参数已对用户隐藏）。

部署地址示例：`http://124.222.208.237:8080`

---

## 1. 登录与语言

1. 打开站点 → **邀请码登录**（可重复使用，约 30 天）。
2. **换语言**：页面右上角地球图标旁的下拉框，可选中/英/印尼等。选中后即时切换；AI 背调摘要跟随界面语言。

---

## 2. 标准工作模式（地图表单）

首页只有**标准工作界面**：国家 → 在哪里 → 找什么 → 半径 → 开始搜索。  
系统一律 **深度全量**（网格 + 不限数量）。无模式切换。

智能体工作区在独立地址：`/agent/`（豆包式对话 + 侧栏新建/历史任务）。

---

## 3. Agent 标准流程（用户输入自然语言之后）

**用户只需发送一句话。** 没有单独的「理解 / 分发」——一次输入跑完整条流水线：

```
用户自然语言
  → 1. IntentAgent     解析：国家 / 地点 / 关键词 / 半径
  → 2. PlannerAgent    拆成深度全量子任务（大都会多区县重叠覆盖）
  → 3. LocalizerAgent  关键词本地化 + 坐标锚定
  → 4. DispatcherAgent 创建排队任务（deep + grid + 不限数量 + 自动背调）
  → 5. Scraper         公平准入满速抓取
  → 6. 结果汇总大表    全部子任务结果合并；可点子任务筛看持续增加的结果
  → 7. IntelAgent      每条结果一出现即自动开始背调；点行展开详情
```

前端用 AI Elements：`Reasoning` / `ChainOfThought` / `Task` / `PromptInput` / `Suggestion`。  
未实现能力（客户画像营销、R1、联网搜索、附件）不在界面展示。

### 为什么可能看不到「思考过程」？

| 情况 | 原因 |
|------|------|
| AI 未配置 | 未设置 `GRSAI_API_KEY` 时 Intent 走**规则引擎**，没有大模型思维链文本；但仍有步骤摘要 |
| 配置了 AI | 默认模型 **`gemini-3.1-flash-lite`**（`GRSAI_MODEL` 可改），中间步骤摘要会显示 source=ai |

### AI 模型（真实服务）

- `GRSAI_API_KEY`（启用）、`GRSAI_API_HOST`（默认 `https://grsaiapi.com`）、`GRSAI_MODEL`（默认 `gemini-3.1-flash-lite`）
- Intent / 翻译 / 背调归纳共用该通道

### 尽量找全

- 点名大城市且未写小半径 → 默认都会区 **40km** + 多区县锚点
- 写了明确公里数 → 尊重用户

之前「雅加达 87 家」是 **3km 烟测**，不是全市。

---

## 4. 必填项（标准模式）

目标国家、在哪里、找什么、目标半径。

---

## 5. 代理

用户无需填代理。服务器用 `GMS_PROXIES` / `-proxies`。

---

## 6. 并发：宁少勿慢 + 水平扩展

- 每深度任务固定 **2 worker**；超槽位排队。
- 槽位 ≈ `min(环境上限, 内存, CPU/2)`。
- 数百并发：多机 `-web` worker 水平扩展。

---

## 7. API

- `POST /api/v1/agent/dispatch` — **唯一用户向入口**（含全流程 + `steps` 中间输出）
- `POST /api/v1/agent/understand` — 调试用预览（产品 UI 不单独暴露）
- `GET /api/v1/system/concurrency`
- `GET /api/v1/ai-status`
