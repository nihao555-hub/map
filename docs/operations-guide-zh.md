# 地图获客 · 完整操作文档

面向业务用户的操作说明（技术参数已对用户隐藏）。

部署地址示例：`http://124.222.208.237:8080`

---

## 1. 登录

1. 打开站点，未登录会跳到 **邀请码登录** 页。
2. 输入管理员发放的邀请码（可重复使用）。
3. 点击 **验证并进入**。会话约 30 天。

**切换语言**：右上角语言下拉框（中文 / English / Bahasa Indonesia / 泰越菲等）。界面语言也会影响 AI 背调摘要语言；地图搜索仍可用当地原语言关键词。

---

## 2. 发起一次搜索（推荐流程）

**必填项**：

| 字段 | 说明 |
|------|------|
| 目标国家 | 必选，决定语言与地图锚定 |
| 在哪里 | 必填城市/区域，或地图点选 |
| 找什么 | 必填品类关键词 |
| 目标半径 | 必填（1–50 公里），**唯一由用户控制的覆盖范围** |

1. **先选目标国家**（如印度尼西亚）——地图会自动飞到该国。
2. **在哪里**：输入城市（如 `雅加达` / `Jakarta`），或在地图上点选。
3. **找什么**：优先用当地语言关键词；也可用中文（勾选 AI 翻译）。
4. 设置 **目标半径**（公里）。
5. 可选：打开 **商家背调**。
6. 点击 **开始搜索**。

系统 **一律深度全量搜索**：浏览器深度抓取 + 半径内网格铺满，**不设数量上限**（不再有「固定 20 家」或快速模式）。数量与滚动深度由系统自动拉满，用户只调半径。

也可使用顶部 **一句话描述目标** →「理解并填入」或「智能分发全量任务」（IntentAgent → Planner → Localizer → Dispatcher）。

右侧 **任务进度** 会显示排队/进行中/已完成。同一账号可并行多个任务（服务器默认最多 **4 路**，并按内存自动降并发）。

---

## 3. 代理说明

高级搜索里的 **用户代理输入已移除**。抓取出口由服务器环境变量配置：

- `GMS_PROXIES` / 启动参数 `-proxies`：Maps 抓取代理池
- 可选：`SEARCH_PROXY` / Clash 节点用于 OSINT 搜索

若部署使用了 `docker-compose.deploy.yaml` + `docker-compose.proxy.yaml`，代理在服务端统一注入，用户无需填写。

---

## 4. 地图点选 / 当前区域搜索

- 在地图上点击：写入锚点，并逆地理同步地点与国家。
- **在当前区域重新搜索**：会先解析当前视野中心的国家/地名再提交。  
  **不要**在未选国家时，于默认中国地图上点选却期望搜印尼——请先选国家。

系统不会再把裸坐标拼进 Google 搜索词。

---

## 5. 查看结果与导出

1. 点击右侧任务条目 → 弹出结果表。
2. 可在地图上查看分布，表格含名称/电话/邮箱/WhatsApp/网站等获客字段。
3. 点击 **导出 CSV** 下载（UTF-8，Excel 可直接打开）。
4. 若开启背调：点击表格行查看公司摘要与决策人（语言跟随界面语言）。

---

## 6. 终止任务

对 **进行中 / 排队中** 的任务，任务坞提供 **终止** 按钮。已抓到的部分结果仍可导出。

---

## 7. 并发与内存（小规格服务器）

| 项目 | 值 |
|------|----|
| CPU | 2 核 |
| 内存 | ~3.6 GB |
| 任务并发上限 `GMS_WEB_JOB_CONCURRENCY` | **4** |
| 实际并发 | **按可用内存自适应**（`AdaptiveJobConcurrency`） |
| 单任务内部并发 | 深度模式硬顶 2，避免 Playwright OOM |
| 海量去重 | 低内存时启用 **Bloom Filter**（`GMS_BLOOM_DEDUP`，谷歌 Bigtable/LevelDB 同思路） |

结果流式写入 CSV，不把全量商户对象长期堆在内存里。

---

## 8. Agent 工作流

自然语言目标会经过：

1. **IntentAgent** — 理解国家/地点/关键词/半径/是否背调  
2. **PlannerAgent** — 拆成多个原子深度全量任务  
3. **LocalizerAgent** — 译成目标国 Maps 可搜词  
4. **DispatcherAgent** — 创建任务（强制 deep + grid + MaxResults=0）  
5. **IntelAgent**（可选）— 抓取完成后再背调  

API：`POST /api/v1/agent/understand`、`POST /api/v1/agent/dispatch`。

---

## 9. 常见问题

**Q: 为什么不再有快速模式？**  
A: 快速模式结果薄、易停在约一页（~20 家）。现统一深度全量，保证数量与质量。

**Q: 界面怎么切换语言？**  
A: 右上角语言下拉框。

**Q: 代理还要自己填吗？**  
A: 不用。服务器已用 `GMS_PROXIES` 配置时即可。

**Q: 谷歌 Bloom 内存算法能用吗？**  
A: 可以。全量网格去重键很多时，Bloom 用极少内存做近似去重；本项目在可用内存偏低时自动启用（前段仍 exact，避免误伤）。
